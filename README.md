\# BridgePass



\*\*A skills passport that turns evidence into employability for skilled refugees, even when paperwork is missing.\*\*



Built for the ILO Mini-Hackathon, "Unlocking Displaced Talent: Pathways for Skilled Refugees."



\## What it does

BridgePass tackles the three barriers that cause "brain waste" in one flow:



1\. \*\*Verify:\*\* a 0-100 competency evidence score built from documents, references, work samples, language ability and short task challenges, plus a bridging plan for whatever is missing.

2\. \*\*Unlock:\*\* a readiness checklist for work authorization, ID and payment access (bank or mobile money).

3\. \*\*Connect:\*\* role matches for returnships, fellowships and remote work, opened once the candidate is verified-ready.



\## SDGs

4 (quality education), 8 (decent work), 10 (reduced inequalities), 16 (strong institutions), 17 (partnerships).



\## Run it

Open `index.html` in any browser. No build step or dependencies.



\## Limits

This is a demo. Scoring is rule-based on self-reported data, and legal guidance is generic. A live version needs partner assessors and country-specific, partner-maintained rules.



\## Roadmap

Pilot with 3 occupations and 5 hiring partners, validate scores against assessor interviews, then add regulator recognition pathways and a candidate-owned shareable passport.
